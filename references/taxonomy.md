# 生图提示词分类体系

这套分类按**最终交付物**划分，而不是按画面里有什么划分。  
例：一张带产品的海报，主类是「海报、字体与封面」，产品只是主体；一张带商品的 App 页面，主类是「UI/UX 与游戏界面」。

选择主类后，只沿用该主类的模板；次要元素用对应词库补充，不要把两个完整模板拼在一起。

## 1. 商业广告与产品视觉

**小类**
- 电商主图 / 白底产品图
- 产品英雄 KV（Hero shot）
- 包装设计 / 结构板 / 刀模图
- 产品参考表 / 多视图一致性表
- 技术分解图 / 爆炸图 / 剖面图
- 极简创意广告（实物 + 涂鸦 / 负空间 / 双关）
- 食品饮料广告
- 联名 / 品牌概念 KV
- 场景化产品图 / 产品 mockup

**路由词**：产品、卖点、转化、电商、主图、详情页、广告、KV、包装、瓶身、罐身、成分、材质、爆炸图、参考表、白底、棚拍。

**默认策略**
- 一张图只讲一个卖点；产品必须是绝对视觉中心。
- 先定产品材质、标签、颜色、比例，再定场景与道具。
- 电商主图用纯净背景；广告 KV 用概念场景；包装用结构视图 + 材质标注。
- 食品要写新鲜线索：水珠、蒸汽、酥屑、油脂光泽、冷凝。

**常见失败**：产品被道具抢走注意力；标签文字乱码；材质像塑料；光线平；画面塞满卖点。

## 2. 品牌识别与 Logo

**小类**
- 图形标 / 字标 / 组合标
- 负空间 / 几何构成 / 字母变形
- VI 视觉识别系统板
- App 图标 / 3D 图标
- 品牌色 / 字体 / 辅助图形
- 吉祥物 / IP 角色
- 名片 / 信纸 / 包装 / 门头应用

**路由词**：Logo、标志、品牌、VI、视觉识别、商标、图标、吉祥物、品牌规范、品牌手册、应用系统。

**默认策略**
- Logo 先写“一个概念”，再写几何构造、负空间、笔画、比例、色数。
- 默认扁平矢量、可缩放、1–2 色；需要 3D 图标时单独说明材质与光。
- VI 板用编辑网格：Logo 网格、概念草图、色板、字体、应用 mockup、标注。
- 品牌名必须给出准确拼写；没有品牌名时用虚构名或 `[品牌名]`。

**常见失败**：Logo 里塞太多元素；渐变与 3D 倒角默认开启；品牌名拼错；VI 板像拼贴画没有网格。

## 3. 海报、字体与封面

**小类**
- 活动 / 促销 / 开业海报
- 电影 / 剧集海报（分层蒙太奇、胶片条）
- 旅行 / 复古 / 丝网印海报
- 杂志 / 编辑封面
- YouTube / B 站 / 视频封面
- 社交海报 / 语录卡 / 引言卡
- 字体实验 / 高密度中文排版
- 邀请函 / 菜单 / 传单 / 节目单

**路由词**：海报、封面、标题、排版、字体、宣传、上映、活动、邀请函、缩略图、KV、主视觉。

**默认策略**
- 先定一个视觉隐喻或一个主画面，不要用十个元素讲十件事。
- 版式写清楚：标题区、主视觉区、正文区、底部信息区。
- 文案写准确：语言、字数、字体类别、层级、位置、对齐。
- 印刷类加纸张、网纹、套印偏差、边缘磨损等质感词。

**常见失败**：文字太多；标题与背景对比不足；字体风格冲突；主视觉与文案各说各话。

## 4. 信息图与知识可视化

**小类**
- 百科 / 科普知识图谱
- 数据图表 / 仪表盘信息图
- 教程 / 流程 / 步骤图
- 教育卡 / 词汇卡 / 学习卡
- 地图 / 美食地图 / 城市指南
- 解剖 / 工程 / 技术图
- 文档 / 证书 / 报纸 / 处方 / 护照
- PPT / 演示封面 / 页面
- 姿势 / 动作 / 舞蹈参考表
- 多格 Storyboard Infographic

**路由词**：信息图、图表、解释、科普、教程、流程、知识、数据、地图、文档、PPT、参考表、拆解、标注。

**默认策略**
- 先定信息结构：中心主体 + N 个模块 + 连接线 + 图例。
- 模块数量、标题、每条内容都要写清楚；数字与单位要准确。
- 文字要短：模块标题 ≤ 8 字，正文每条 ≤ 20 字，避免长段落。
- 用网格、编号、细线、箭头、色块建立层级。

**常见失败**：信息密度高但不可读；标注线乱飞；假数据；文字乱码；中心主体与模块无关。

## 5. UI/UX 与游戏界面

**小类**
- 移动 App 首页 / 详情页 / 播放器
- 网页 Landing Page
- Dashboard / 数据后台
- 设计系统 / 组件库
- 社交平台截图 / 直播界面
- 游戏 HUD / 游戏截图
- 电商详情页 / 商品卡
- 智能设备 / 车载界面

**路由词**：App、界面、UI、UX、网页、Dashboard、后台、截图、直播、HUD、组件、设计系统、交互。

**默认策略**
- 先定设备与画布，再定状态栏、导航、内容区、底部栏。
- 每个模块写清楚：位置、元素、数量、精确文案、图标风格。
- 指定字体、圆角、阴影、间距、主色/强调色、明暗模式。
- 用“真实量产界面截图，不是概念稿”压住概念化倾向。
- 游戏 HUD 要写“底层 3D 场景 + 上层 HUD”，并分别描述。

**常见失败**：文字模糊/乱码；组件重复；间距不一致；图标风格混搭；像 Dribbble 概念图而不是真实产品。

## 6. 摄影与写实影像

**小类**
- 人像 / 头像
- 时尚编辑大片（Editorial）
- 生活方式 / 纪实抓拍
- 手机快照 / CCD / 宝丽来
- 美食摄影
- 建筑 / 室内 / 空间
- 旅行 / 风景
- 产品摄影
- 电影剧照
- 黑白 / 胶片 / 实验摄影

**路由词**：照片、摄影、写实、人像、街拍、胶片、大片、美食、室内、建筑、风景、抓拍、剧照。

**默认策略**
- 人物要具体到：年龄区间、族裔（如相关）、脸型、眼睛、发型、妆容、服装材质、姿态、视线。
- 镜头写：景别、机位、焦距、光圈、景深、构图。
- 光线写：光源、方向、软硬、色温、实用光、反光。
- 质感写：皮肤纹理、毛孔、绒毛、织物、颗粒、轻微瑕疵。
- 真实感来自“不完美”：轻微运动模糊、构图偏移、环境杂物、自然阴影。

**常见失败**：塑料皮肤；过度磨皮；光线没有方向；人物像摆拍假人；背景像影棚背景板。

## 7. 插画与漫画

**小类**
- 儿童绘本 / 童话插画
- 国风 / 工笔 / 水墨
- 日漫 / 二次元 / 赛璐璐
- 美漫 / 讽刺漫画 / Graphic Novel
- 线稿 / 素描 / 版画 / 丝网印
- 水彩 / 拼贴 / 纸雕
- 矢量 / 扁平 / 极简
- 漫画分格 / Webtoon
- 角色插画 / 同人

**路由词**：插画、动漫、漫画、绘本、国风、水彩、线稿、矢量、二次元、赛璐璐、版画、拼贴。

**默认策略**
- 写“媒介 + 流派/时代 + 技法 + 线条 + 上色 + 纹理 + 色板”。
- 不要只写“好看/高级”；换成可观察特征：线宽、边缘、笔触、阴影块、纸张。
- 漫画要写分格、阅读顺序、对白气泡、拟声词、出血与留白。
- 儿童插画要简化解剖、柔和色板、纸纹，明确“不要写实/3D”。

**常见失败**：风格词堆砌但互相冲突；线条脏；角色每格长得不一样；把插画做成 3D。

## 8. 3D 渲染与潮玩

**小类**
- 产品 3D 渲染
- 潮玩 / 手办 / 收藏玩具
- Q 版 / Chibi / 毛绒化
- 3D 图标 / Logo
- 等距 / 微缩场景
- 材质实验（玻璃、金属、毛绒、黏土、果冻）
- 盲盒 / 卡牌

**路由词**：3D、渲染、手办、潮玩、盲盒、图标、黏土、毛绒、等距、微缩、C4D、Blender。

**默认策略**
- 写几何、比例、材质（PBR）、表面处理、光源、地面阴影、渲染器。
- 潮玩要写头身比、关节线、底座、包装、哑光/亮面。
- 3D 图标要写圆角方形底板、倒角、材质、背景、无文字。
- 微缩场景要写比例线索、底座、微小人/物、移轴感。

**常见失败**：材质像塑料；没有接触阴影；几何畸变；光源过多；像 2D 插画。

## 9. 角色设计与一致性

**小类**
- 角色设定表（三视图 / 表情 / 服装 / 道具）
- 头像 / Profile
- 参考图换装 / 换风格
- 角色卡 / 卡牌
- 吉祥物 / IP
- 游戏角色 / Cosplay
- 多角色关系图

**路由词**：角色、人设、三视图、设定表、头像、换装、同一个人、保持一致、身份、参考图。

**默认策略**
- 先写“角色身份锁”：脸型、眼睛、眉毛、鼻子、嘴唇、肤色、发型、发际线、体型。
- 再写“可变项”：服装、场景、光线、媒介。
- 多格必须写“同一角色在所有格子中完全一致”，并重复关键特征。
- 设定表写：主视图、三视图、表情组、动作、道具、色板、信息框。

**常见失败**：每格换脸；服装漂移；年龄变化；美化过度；参考图身份没锁住。

## 10. 场景叙事与分镜

**小类**
- 电影感单帧 / 剧照
- 多格分镜 / Storyboard
- 漫画页 / 条漫
- 游戏 Key Art / 概念场景
- 历史 / 古风 / 武侠
- 超现实 / 巨物 / 微缩叙事
- 旅行叙事 / 城市切片
- 广告分镜

**路由词**：场景、分镜、故事、电影感、剧照、漫画页、概念图、古风、武侠、超现实、巨物、微缩。

**默认策略**
- 先写“故事节拍”：这一帧之前发生了什么、人物在做什么、下一帧会怎样。
- 写环境三层：前景、中景、背景；写天气、时间、空气感。
- 写镜头：景别、机位、焦距、运动感、画幅。
- 多格分镜先写共享角色/场景/色板，再逐格写动作与台词。

**常见失败**：只是“好看的场景”没有故事；人物与环境比例错；分镜每格风格不统一；镜头语言混乱。

## 11. 社交内容与个人品牌

**小类**
- 社媒帖子 / 九宫格
- 小红书 / Instagram 封面
- 个人头像 / Profile
- 直播截图 / 弹幕
- 梗图 / 表情包
- 语录卡 / 引言卡
- Scrapbook / 拼贴
- 视频封面

**路由词**：发圈、小红书、社交媒体、头像、直播、表情包、梗图、九宫格、语录、封面、涨粉。

**默认策略**
- 先定平台与比例：小红书/IG 4:5，故事/直播 9:16，视频封面 16:9。
- 写“钩子”：一句短标题、一个强情绪脸、一个对比色块。
- 手机端可读：标题 ≤ 8 字，副文案 ≤ 20 字，字号大、对比强。
- 平台截图要写平台 chrome、状态栏、头像、用户名、点赞评论、时间。

**常见失败**：字太多；对比弱；像海报不像平台内容；平台 UI 元素缺失或错误。

## 12. 图像改造与风格迁移

**小类**
- 风格迁移（照片转动漫 / 油画 / 3D / 吉卜力）
- 滤镜 / 胶片 / 年代感
- 换背景 / 清场 / 路人消除
- 换装 / 造型改造
- 角色替换 / 身份保持
- 图像扩展 / 局部重绘
- 多图融合 / 拼贴
- 产品转潮玩 / 徽章 / 包装

**路由词**：把这张图、参考图、改成、换成、去除、融合、保持、同款、风格迁移、清场、扩图。

**默认策略**
- 先写“保留清单”，再写“改变清单”，最后写“禁止项”。
- 只有一张参考图时写“附图为唯一参考”；多图时写“图 1 管身份、图 2 管服装、图 3 管风格”。
- 清场要写“用符合场景逻辑的背景填充，匹配颗粒、景深、光线、透视”。
- 风格迁移要写“保留构图/身份/姿势，只改媒介与质感”。

**常见失败**：换风格把脸也换了；清场留下模糊补丁；多图融合把身份混在一起；扩图出现重复结构。

## 组合与歧义规则

1. **按交付物定主类**：海报里的产品、UI 里的商品、信息图里的插画，都只是主体，不改变主类。
2. **只借一个次要模板**：主类模板 + 次要词库，不叠加两套完整结构。
3. **主体优先于风格**：用户描述里名词是主体，形容词是风格；先保证主体可识别，再谈风格。
4. **不确定时选更常见的交付物**：没有说明用途时，默认社媒竖版 4:5；没有人像/产品特殊要求时，默认写实摄影。
5. **参考图优先**：用户给了图，默认进入「图像改造」，除非明确说“只参考风格/只参考构图”。
6. **多格优先**：用户说“九宫格、分镜、表情包、多视角、三视图”，优先进「角色设计」或「场景分镜」，并加一致性协议。

## 跨类标签怎么落位

库里有几个标签跨多个主类，不要为它们单开大类：

- **游戏与娱乐**：游戏 Key Art / 概念场景 → 场景叙事；游戏 HUD / 截图 → UI；游戏道具 / 卡牌 / 像素素材 → 3D 或插画。
- **视频、动画与拼贴**：分镜、关键帧、电影叙事 → 场景分镜；拼贴、Scrapbook → 社交内容或海报。
- **文字渲染**：海报、信息图、UI、品牌类处理；摄影/插画默认无文字。
- **个人资料 / 头像**：角色设计或社交内容；写实头像归摄影。
- **旅游 / 建筑 / 装修 / 美食**：按交付物落位——照片归摄影，海报归海报，地图归信息图。
- **Tech / featured / original / 来源名 / 模型名**：元数据标签，不作为内容分类。
