# 分类型提示词配方

每个配方都按「必填槽位 → 结构骨架 → 默认值 → 负面」使用。  
槽位用 `【】` 标记；交付时把槽位替换成具体内容，不要保留空括号。

## 1. 电商主图 / 白底产品图

**适用**：平台主图、SKU 图、白底图、产品对比图。  
**必填槽**：产品名、品类、材质、颜色、关键结构、标签文字、比例。  
**结构骨架**

```text
一张用于电商主图的【比例】产品图。画面中央是【产品名/品类】，【材质与颜色】，【关键结构/形状/容量】，【标签或 logo 文字】必须清晰可读。
产品完整入镜，占画面约 70%–80%，正面略偏 3/4 视角，镜头与产品同高或略低。
背景为纯净的【白色/浅灰/品牌色】无缝背景，地面有柔和接触阴影，无多余道具。
布光为【大型柔光箱主光 + 两侧补光/顶部柔光】，产品边缘有干净高光，材质纹理真实，颜色准确不过饱和。
商业产品摄影，超写实材质，8K 细节。不要出现文字乱码、额外 logo、水印、杂物或变形。
```

**默认**：1:1；2k；白色无缝背景；柔和棚拍光；产品占 75%。  
**负面**：plastic-looking, flat lighting, wrong label, extra text, clutter, watermark, distorted shape.

## 2. 产品英雄广告 KV

**适用**：品牌 campaign、社媒广告、落地页 hero、户外大屏。  
**必填槽**：产品、核心卖点、目标人群、 campaign 概念、文案、品牌色、比例。  
**结构骨架**

```text
一张【比例】的高端产品广告主视觉，为【品牌/产品】打造，核心概念是【一句话视觉隐喻】。
产品位于【画面位置】，【材质/颜色/标签】清晰可见，占画面约【55%–70%】；周围是【与概念相关的道具/元素】，形成【互动关系】。
背景为【场景/渐变/纯色】，前中后景层次清楚，【负空间位置】留给标题与 logo。
构图：【中心/三分/对角线/框架式】，【低角度/平视/俯视】，【浅景深】。
光线：【主光方向/软硬/色温】，产品表面有【高光/反射/焦散】，整体色调【色板】。
风格：商业广告摄影，超写实，材质细节丰富，8K。
文字：主标题「【文案】」位于【位置】，【字体风格】；logo 位于【位置】；只出现这些文字。
```

**默认**：4:5 或 9:16；2k；一个卖点；产品为绝对主体；文案 ≤ 10 字。  
**负面**：competing props, cluttered layout, flat light, plastic texture, gibberish text, watermark.

## 3. 包装设计 / 产品参考表 / 爆炸图

**适用**：包装提案、工业设计板、产品多视图、技术拆解、成分说明。  
**必填槽**：产品、包装类型、材质、结构、视图数量、标注内容、品牌色。  
**结构骨架**

```text
一张【比例】的专业产品设计板，主题为【产品/包装】。
中心是【3D 英雄渲染/实物照片】，材质为【纸/塑料/玻璃/金属/织物】，表面处理为【哑光/亮面/烫金/压纹】。
周围是技术视图：【正面/侧面/顶部/底部/3/4 视角/爆炸视图/剖面图】，共【N】个，等距排列。
标注：【尺寸/容量/材质/结构/工艺/使用方式】，用细线引出，文字为【语言】，字号清晰。
色板：【主色/辅色/强调色】；背景为【纯白/浅灰/牛皮纸】摄影棚背景，柔和阴影。
风格：工业设计作品集，真实渲染 + 手绘草图混合，超精细。
```

**默认**：4:3 或 1:1；2k；白底；3–6 个视图；标注简短。  
**负面**：wrong structure, impossible geometry, unreadable labels, floating parts, watermark.

## 4. Logo / VI / App 图标

**适用**：品牌标志、视觉识别系统、图标、品牌手册页。  
**必填槽**：品牌名、行业、核心概念、图形元素、色板、应用场景。  
**结构骨架（Logo）**

```text
为【品牌名/行业】设计一个【图形标/字标/组合标】。核心概念是【一个视觉想法】，通过【负空间/几何构成/字母变形/象征图形】实现。
造型简洁、可缩放、轮廓清晰，默认扁平矢量，【1–2】色，无渐变、无 3D 倒角、无阴影。
主色【色值/颜色名】，辅助色【色值/颜色名】。背景为纯白或浅灰。
输出：Logo 居中，留出安全边距；可附【黑白稿/反白稿/网格比例】。
```

**结构骨架（VI 板）**

```text
一张【比例】的品牌视觉识别系统板，品牌为【品牌名】，行业为【行业】。
版面为【3×4/2×3】编辑网格，包含：Logo 主视觉、Logo 网格与比例、概念草图【N】张、色板【N】色、字体规范、辅助图形、应用 mockup【N】个（【杯子/纸袋/名片/门头/包装】）。
风格：现代、克制、品牌手册级排版，米白纸张背景，细线标注，所有文字为【语言】。
```

**默认**：Logo 1:1；VI 4:3；2k/4k；品牌名必须准确。  
**负面**：too many colors, gradients, illegible wordmark, complex illustration, 3D bevel, watermark.

## 5. 活动 / 电影 / 旅行海报

**适用**：活动宣传、电影/剧集海报、旅行海报、复古印刷海报。  
**必填槽**：主题、主视觉、标题、副标题、时间/地点、风格、比例。  
**结构骨架**

```text
一张【比例】的【类型】海报，主题为【主题】。
主视觉：【一个核心画面/视觉隐喻】，位于【位置】，占画面约【60%】；前景【元素】，中景【元素】，背景【元素】。
构图：【中心/对角线/S 型/分层蒙太奇】，【留白位置】用于文字。
光线与色彩：【光源/方向/色温】，色调为【色板】，【胶片颗粒/丝网印/纸张纹理】。
文字层级：
- 主标题「【标题】」：【字体类别/字重/大小/位置/对齐】
- 副标题「【副标题】」：【字体类别/大小/位置】
- 信息「【时间/地点/票务】」：【字体类别/大小/位置】
风格：【复古旅行/电影海报/国潮/极简 editorial】，只出现以上文字，无乱码、无额外文案。
```

**默认**：4:5 或 3:4；2k；主标题 ≤ 10 字；最多 3 层文字。  
**负面**：too many fonts, low contrast, cluttered, gibberish text, watermark, extra logos.

## 6. 视频封面 / YouTube 缩略图 / 社媒封面

**适用**：YouTube、B 站、短视频、播客、社媒封面。  
**必填槽**：主题、人物/主体、情绪、标题、平台、比例。  
**结构骨架**

```text
一张【比例】的【平台】视频封面，主题为【主题】。
主体：【人物/产品/场景】，位于【位置】，占画面【50%–70%】，表情/动作【强情绪/动作中】，与镜头有眼神接触。
背景：【对比色块/场景/渐变】，【箭头/圆圈/高亮】指向主体或标题。
文字：主标题「【3–5 个词/≤8 个汉字】」，【超粗无衬线/黑体】，【颜色】，带【描边/投影/色块】，位于【位置】；副标题「【可选】」更小。
风格：高对比、手机端可读、信息一眼抓住；不要超过 2 个文字块。
```

**默认**：16:9；2k；标题 ≤ 8 字；高饱和对比。  
**负面**：small text, low contrast, too many words, cluttered, watermark.

## 7. 信息图 / 百科 / 数据 / 教程

**适用**：科普、知识图谱、数据图、教程、流程、教育卡、地图。  
**必填槽**：主题、中心主体、模块数量、每模块标题与要点、数据、语言、比例。  
**结构骨架**

```text
一张【比例】的【语言】信息图，主题为【主题】，目标是【解释/比较/教学/说服】。
中心：【主体/核心图示】，位于画面【位置】，占【40%–55%】，【写实/插画/3D】风格。
周围：【N】个信息模块，按【网格/环绕/左右分栏】排列：
1. 「【模块标题】」：【1–2 句要点/数据】
2. 「【模块标题】】：...
（写满 N 个）
用【细线/箭头/括号/编号】把模块与中心主体连接；每个模块有【图标/小图/数据条】。
版式：清晰网格、充足留白、标题层级分明；主标题「【标题】」位于【位置】，字体【字体类别】。
色板：【主色/辅色/强调色】；背景【纸张/纯色/深色】；风格【editorial infographic/科学百科/现代数据可视化】。
所有文字必须清晰可读，只出现以上内容，数据不得虚构。
```

**默认**：3:4 或 16:9；2k/4k；模块 4–8 个；每模块 ≤ 2 行。  
**负面**：fake data, gibberish, overcrowded, unreadable labels, random arrows, watermark.

## 8. 文档 / PPT / 证书 / 地图

**适用**：演示封面、PPT 页面、证书、报纸、处方、护照、菜单、城市地图。  
**必填槽**：文档类型、标题、机构/品牌、日期、正文要点、语言、风格。  
**结构骨架**

```text
一张【比例】的【文档类型】，语言为【语言】。
版面：【A4/16:9/竖版】，【页眉/标题区/正文区/页脚】；主标题「【标题】」用【字体类别】，副标题「【副标题】」用【字体类别】。
正文：【3–5】个要点/段落，每段【≤20 字】，左对齐/居中对齐，行距【松/紧】。
视觉：【印章/签名/日期/编号/边框/纸张纹理/折痕】，颜色【色板】，印刷质感【凸版/胶印/烫金】。
风格：【正式/复古/极简/学术】，只出现以上文字，不添加无关内容。
```

**默认**：A4 3:4 或 PPT 16:9；2k；文字短、层级少。  
**地图变体**：手绘/等距地图，写清地标、美食点、路线、图例、比例尺、吉祥物；每个点有编号与名称，背景为羊皮纸/米色纸。  
**负面**：gibberish, fake signatures, wrong date, cluttered, watermark.

## 9. 移动 App / 网页 / Dashboard

**适用**：App 首页、详情页、播放器、Landing Page、后台、设计系统。  
**必填槽**：产品类型、页面、设备、明暗模式、主色、模块、精确文案、比例。  
**结构骨架**

```text
一张高保真的【设备/画布】界面截图，产品为【产品类型】，页面为【页面】，【浅色/深色】模式，主色【色值/颜色】。
从上到下：
- 状态栏：【时间/信号/电池】
- 顶部导航：【返回/标题/搜索/头像/更多】，布局【左中右】
- 主内容区：【模块 1】，包含【元素/数量/文案】
- 中部：【模块 2】，包含【卡片/图表/列表/按钮】
- 底部：【标签栏/CTA/播放控制】，包含【N】个入口
精确文案：
- 标题：「【文案】」
- 按钮：「【文案】」
- 标签：「【文案 1】」「【文案 2】」...
视觉：圆角【N】px，间距【8pt 网格】，阴影【柔和/无】，图标【线性/面性/混搭】，字体【无衬线/宋体】。
要求：真实量产界面，不是概念稿；组件对齐、文字清晰、无重复组件、无乱码。
```

**默认**：移动 9:16；网页/后台 16:9；2k；一套图标风格；文案 ≤ 5 块。  
**设计系统变体**：用网格展示色板、字体层级、按钮/输入框/卡片/标签/图标、间距与圆角、明暗模式；每个组件标注名称与状态；背景浅灰，无真实业务文案。  
**负面**：blurry text, fake UI, duplicated widgets, misaligned bars, warped characters, low-res, watermark.

**必填槽**：平台/游戏、场景、主角、HUD 元素、文案、比例。  
**结构骨架**

```text
一张【比例】的【游戏/平台】截图。
底层场景：【3D 场景/直播画面/视频画面】，主体【人物/场景】，镜头【第三人称/第一人称/中景】，光线【氛围】。
上层 UI：
- 左上：【头像/等级/血条/状态】
- 右上：【小地图/金币/设置】
- 左下：【技能栏/聊天/队伍】
- 右下：【任务/背包/操作按钮】
- 中部：【准星/伤害数字/提示】
精确文案：「【角色名】」「【等级】」「【任务】」「【按钮】」...
平台 chrome：【状态栏/导航栏/评论输入框/点赞评论数】。
视觉：游戏 HUD 级精致，组件不重叠，文字清晰，图标风格统一；截图真实感。
```

**默认**：游戏 16:9；直播/社交 9:16；2k；HUD 元素 ≤ 12 个。  
**负面**：overlapping widgets, warped characters, low-res UI, duplicated HUD, fake text, watermark.

**结构骨架**


## 13. 插画 / 儿童 / 国风 / 漫画

**适用**：绘本、国风、二次元、美漫、线稿、水彩、拼贴、漫画页。  
**必填槽**：主题、媒介、流派、线条、上色、色板、纹理、比例。  
**结构骨架**

```text
一张【比例】的【媒介/流派】插画，主题为【主题】。
```
