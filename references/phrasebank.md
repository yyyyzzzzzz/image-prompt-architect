# 提示词词库与句式

原则：**用可观察的词，不用空泛形容词。**  
每个维度写 1–3 个最关键的词，不要把所有词都塞进去。

- 年龄区间：early 20s / late 20s / mid-30s / 50s；中文写“20 岁出头 / 近 30 岁 / 35 岁左右”，避免模糊的“年轻”。

## 16. 高频句式

**主体与场景**
- “A 【subject】, 【appearance】, 【pose/action】, set against 【environment】.”
- “The subject occupies 【percentage】 of the frame, with 【foreground】 in front and 【background】 softly blurred behind.”

**镜头与光线**
- “Shot on a 【camera/lens】 at 【aperture】, 【shot size】, 【angle】, with 【lighting setup】.”
- “【Direction】 light from 【source】, 【hard/soft】, 【color temperature】, creating 【shadow/highlight】.”

**设计与版式**
- “Use a 【grid】 layout with 【N】 equal modules, 【gutter】 gutters, and 【margin】 margins.”
- “Place 【element】 in the 【position】; keep 【area】 as negative space.”
- “All text must be legible; only these words: 【copy】.”

**一致性与改造**
- “Use the attached image as the only reference. Preserve 【list】; change only 【list】; do not 【list】.”
- “The same character must appear in all 【N】 panels with identical 【face/hair/outfit/proportions】.”

**负面/边界**
- “No watermark, no signature, no extra text, no gibberish.”
- “Do not add 【unwanted element】; keep the composition clean and uncluttered.”
